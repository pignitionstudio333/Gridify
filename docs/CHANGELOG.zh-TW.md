# 版本紀錄

## 1.2.0 - 2026-10-30
### 新增
- **版本紀錄／檢查更新**：系統匣選單 →「版本紀錄／檢查更新…」。版本紀錄內建在程式裡，不用連網；按下「檢查更新」才會連到 GitHub 問最新版本，有新版時可前往下載頁面。可選擇「每天自動檢查更新」（預設關閉）。程式不會自動下載或安裝任何東西。
- **升級前自動備份設定**：偵測到版本改變時，先把設定檔另存到備份資料夾（`before-upgrade-<版本>.json`）。
- **只有一個分頁的收納區，按住 Ctrl 拖曳標題**到其他收納區，就會整個併成它的新分頁（分頁沿用原收納區的名稱）。原收納區會消失；「桌面」收納區不會消失，會留下一個空分頁，讓新的桌面項目有地方收納。項目只是路徑參照，不會有捷徑遺失，目標收納區已有的項目不會重複放入。
- 第一次執行的歡迎視窗新增「登入 Windows 時自動啟動 Gridify」勾選（預設不勾，會顯示目前的設定）。

### 變更
- 安裝程式在原地升級時，會先把桌面圖示還給系統，並結束執行中的 Gridify，再替換檔案。
- 隱私：預設仍完全不連網；只有你按下「檢查更新」或開啟每日自動檢查時，才會對 GitHub 發出一個查詢最新版本的 HTTPS 請求，不傳送任何你的資料。

## 1.1.1 - 2026-10-29
### 修正（重大）
- **1.1.0 及更早版本的重大問題：在收納區裡的圖示按右鍵，只會出現 Gridify 自己的選單，缺少 Windows 的功能**（清空資源回收筒、內容、以系統管理員身分執行、傳送到、7-Zip…）。現在圖示的右鍵會顯示 Windows 原本的選單，最下面附上幾個 Gridify 的項目（按住 Shift 再按右鍵可顯示更多選項）。在收納區空白處按右鍵仍是 Gridify 的選單。**使用 1.0.0 / 1.1.0 的人請更新。**

## 1.1.0 - 2026-10-29
### 新增
- **收納區內的分頁**：點標題列的 `+`（或右鍵 > 新增分頁）。有兩個以上分頁時標題列顯示分頁標籤；只有一個分頁時維持原本的樣子。雙擊分頁可改名，右鍵可左移／右移與刪除，分頁很多時在標籤上滾動滑鼠滾輪。
- **在收納區之間移動分頁**：把分頁拖到另一個收納區的標籤列或內容區，連同項目一起移過去；在標籤列內拖曳可調整順序。一般收納區的最後一個分頁被拖走時，該收納區會消失；「桌面」收納區一定保留一個分頁。
- **把項目拖到分頁上**就會放進那個分頁；拖曳時停在分頁上會自動切換過去。
- **依類型整理成分頁**：「依類型整理」可以在「桌面」收納區裡建立分頁（建議），也可以像以前一樣建立獨立的收納區。
- **復原／重做**（Ctrl+Z / Ctrl+Y，右鍵選單與系統匣選單也有）：可復原收納區、分頁與項目歸屬的變動，最多 30 步，絕不動你的檔案；重新命名檔案後會清空。

### 變更
- 設定檔改為儲存分頁，舊檔案會自動轉換；合併後的項目清單仍會寫入，所以退回 1.0.0 項目也不會遺失。
- 收納區新增第二個分頁時，第一個分頁沿用收納區的名稱；回到只剩一個分頁時，收納區改用那個分頁的名稱（「桌面」收納區保留原名）。
- 拖曳標題列的空白處一律是移動收納區。

### 修正
- 收合的收納區展開後高度可能不對。現在只有使用者自己縮放時才會改變展開後的高度。

## 1.0.0 - 2026-10-29
首次公開發佈（由私人工具「Fence」改名而來）。

- 參照模式的桌面收納區：把檔案拖進來，不會搬移或複製。
- 可選的桌面接管，保證還原（結束、當機守護、解除安裝、`--restore`）。
- 項目可在收納區之間自由移動、拖曳排序、收合／展開。
- 外觀設定：圖示大小、背景透明度／顏色、壓克力、陰影、動畫。
- 英文與繁體中文介面。
- 可攜版（`Gridify.exe` 旁的 `data` 資料夾）與安裝版（`%LOCALAPPDATA%\Gridify`）。
- 第一次執行的歡迎視窗與 Shift 安全模式。
- 原子化設定存檔、自動備份、當機記錄。
