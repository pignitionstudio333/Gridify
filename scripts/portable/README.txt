Gridify portable

- Run Gridify.exe. No installation, no registry changes (unless you enable Start with Windows).
- All settings are stored in the "data" folder next to Gridify.exe.
- Your files are never moved or copied; grids only hold references (shortcuts) to them.
- If desktop icons ever stay hidden after a crash, run Restore-Desktop.bat.
- To remove: tray icon > Uninstall (removes the data folder and the Run value), then delete this folder.
- Hold Shift while starting to launch in safe mode (does not hide desktop icons).
